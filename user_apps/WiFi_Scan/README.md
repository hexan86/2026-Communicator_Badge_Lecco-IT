# WiFi scanner

Basic WiFi scanner

After the scan shows a list with:

[dBm, auth, bssid, ssid]

Then you can clear Save the list, Clear the list or select a Network and connect to it.
If you connect to a network, it will show ssid and IP address. 



## Commands

F1 = Scan for networks

F2 = Save list in /notes

F3 = Clear the screen

F4 = Connect to network / Disconnect

F5 = Exit
