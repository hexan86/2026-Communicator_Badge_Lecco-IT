# File manager

Simple file manager for the Communicator Badge

## Controls
F1 = Open directories (Also files, but that's not optimized yet)
F2 = Copy
Shift + F2 = Paste
F3 = Delete
Shift + F3 = Rename
F4 = not assigned
F5 = Exit


## Details
Top-Right corner a counter that shows "selected file/total"
Black selector to give a good contrast to visualize the movement
Unix like navigation backwards with ".." on top of the list
Folders are preceded by [D]


## Why
I've made this app to keep exploring the badge and familiarize with a new topic (micro-python).
Also I think it's nice to have a little navigation system integrated in the badge.

## Known Issues
When using F1 (Open) on a file, it opens a window with the content of the file, but it's not editable and it's not possible to move around the document.
