
# AI Chat Bot - OpenAI


Small app that allows to connect to a your network and that queries gpt-5.4-mini


## Configuration

It requires a registration on OpenAI Dashboard in order to obtain an API KEY.
Once you have the key you have to put it in the cfg.ai file, as the SSID and Key for your network.
A smartphone hotspot will do just fine.
Once you have inserted all the infos in cfg.ai you have to put it in the badge  path /data
The app itself goes in /apps


## Controls

F1 = Wifi    Execute the connection to the network
F2 = Input   PopUp box where to write your text (close with Esc)
F3 = Clear   Clears the chat window
Arrows       Scroll the chat
F5 = Exit
